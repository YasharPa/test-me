# שער החידון

דף חידון (JavaScript / React / Node.js) שחוסם כניסה לאפליקציות באייפון דרך אוטומציה של Shortcuts:
5 שאלות מהקל לקשה, 3 נכונות פותחות את האפליקציה.

- `index.html` – האפליקציה והוראות ההגדרה באייפון
- `questions.js` – מאגר השאלות (התשובה הראשונה בכל שאלה היא הנכונה)

מתארחים כאתר סטטי (למשל GitHub Pages) ופותחים ב-Safari.
